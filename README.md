# 테니스 매칭

동호회 테니스 **대진 생성 · 결과 집계** 앱. 단일 HTML 파일로 동작하며 서버가 필요 없다.

**바로 쓰기 → https://donghakim-hr.github.io/tennis/**

## 무엇을 하는가

- 참가자 **4~16명**, 코트 **1~4면**, **1인당 경기 수 2~6** 설정 → 대진 자동 생성
- **단식 / 동성 복식 / 혼성 복식** 지원. 혼성은 모든 팀을 남 1명 · 여 1명으로 구성
- 같은 사람과 **두 번 짝이 되지 않도록** 배분하고, 목표 경기 수 미달자 0명 · 출전 편차 최대 1경기를 보장
- **실력 등급(A·B·C)** 을 주면 양 팀 전력이 비슷해지도록 팀을 짠다
- 혼성 복식은 **파트너 랜덤 / 고정 조**(부부·커플 조 등) 선택 가능
- 점수를 입력하면 **득실 기준 순위가 실시간 갱신**되고, 입력이 멈추면 자동 저장된다
- 결과를 **링크 하나로 공유**할 수 있다(서버 없이 URL에 담는다). 링크로 열면 읽기 전용
- 날짜별로 기록이 남고, 지난 회차의 **명단을 그대로 불러올 수 있다**

## 쓰는 방식

총무 한 명이 스마트폰으로 입력하고, 결과는 `공유 링크 복사`나 `결과 복사`로 단톡방에 던지는 것을 상정한다.
데이터는 각자 기기에 저장되므로 여러 사람이 동시에 입력하지는 않는다.

## 개발

```bash
git clone https://github.com/donghakim-hr/tennis.git
cd tennis
npm install     # 테스트용 jsdom만 설치 (앱 자체는 의존성 없음)
npm test        # 약 700개 대진 조합 + 기능 + UI 동작 검사
```

앱을 보려면 `index.html`을 브라우저로 그냥 열면 된다. 빌드 과정이 없고, `main`에 push하면 GitHub Pages가 그대로 배포한다.
